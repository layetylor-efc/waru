# CAT DROP GUARDIAN

スマートフォン向けの落ちものパズル＋猫防衛ゲーム。提供された参考画像2枚を使用。

## 完了条件

- 6列×8段の盤面で猫のペアを操作し、同じ猫を縦横に3匹以上そろえる。
- 三毛猫は攻撃、白猫は回復、黒猫はシールド、茶トラは範囲攻撃として自動出撃する。
- 5ウェーブの防衛、勝敗、再挑戦、連鎖、必殺技を実装する。
- タップ、スワイプ、画面ボタン、キーボードで操作できる。
- 一時停止、画面非表示時の停止、途中保存、音の切替を備える。
- 320〜768px・横画面を確認し、既存ゲームの下に入口を追加する。
- index.htmlは画像・CSS・JavaScript内蔵の単体ファイルとして動作する。

## 開発

`node build.cjs` でHTMLを生成。外部ランタイム依存なし。
`node tests/core.test.cjs` でゲームロジックを検証。
`node tests/browser.cjs` でPlaywrightのブラウザ検証（PlaywrightとChromiumが必要）。
ローカルのHTTPサーバーで開くとPWAを含めて確認できます。
`CAT_DROP_GUARDIAN_v1.0.html` はアイコン・マニフェスト参照を外した単体配布版です。

## 操作

左右：列移動、回転：ペアを時計回りに回転、落とす：着地点へ落下。
盤面の列タップ：列移動。上スワイプ：回転。下スワイプ：落下。
キーボード：←→、↑/X、↓（ゆっくり落下）、Space（落下）、S（スキル）、Esc/P（一時停止）。
SP 100で全敵ダメージ＋城回復＋盤面の下2段の猫を出撃させる司令官スキル。

## 素材

assets/key-visual.png と assets/chip-atlas.png はユーザー提供画像の原本。
画像の再生成・書き換えはせず、Canvasの参照範囲指定で使用。
icon.svgはゲーム用に作成した図形アイコン。
広告・アクセス解析・課金・外部フォントなし。

## 保存

端末のlocalStorageにベストスコアと中断データを保存。保存できない環境でもプレイ可能。
公開版はcat-drop-guardian/配下だけをService Workerの対象にする。
file://から開くHTMLではPWA登録をしない。
