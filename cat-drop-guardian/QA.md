# CAT DROP GUARDIAN v1.0.0 — 実装・QA記録

依頼日：2026-10-03（JST）

## 完成した項目

- 6列×8段・猫ペアの落ちものパズル。縦横3匹以上でマッチし、重力と連鎖を解決。
- 三毛猫＝単体攻撃、白猫＝仲間・城の回復、黒猫＝シールド、茶トラ＝範囲攻撃。
- 5ウェーブ防衛、4種類の敵と最終ボス、勝敗、再挑戦、通常／練習モード。
- SP 100で全体攻撃・城回復・盤面の下2段から出撃する司令官スキル。
- タップ、スワイプ、画面ボタン、キーボード、長押し左右移動。
- 一時停止、非表示／フォーカス喪失時の停止、中断保存と再開、ベストスコア。
- 任意の効果音、URL共有、HTML保存、PWAとオフライン起動。
- 参考画像原本を内蔵。猫チップ・司令官はCanvasの参照範囲指定で使用。
- waruトップの既存2ゲームの下に、専用リンクと埋め込みゲームを追加。

## 修正した不具合

1. 長時間の出撃で攻撃待ち時間が負の値に蓄積し、中断データの検証で拒否される問題。待ち時間を0以上に制限し、長時間出撃の回帰テストを追加。
2. 初手の説明に対して三毛猫をそろえにくい初期配置。左端で縦3匹がそろう配置へ修正。
3. 画面比率によって戦闘画像が横または縦に伸びる問題。Canvas内で一様拡大し、画面高さに対応したgroundYを採用。
4. 保存HTMLでタイトルのCanvas準備済みフラグが残る問題。配布時にリセットして、再読み込み時に描き直す。
5. 再開時にも初手案内が出る表示。再開用の司令官メッセージへ変更。
