## 新シリーズの追加方法
1. `index.html` 内の `<article class="series" data-category="...">` をコピーし、番号・作品名・説明・表示文言・状態を変更。
2. `data-category` は `study` または `daily` を使用（別カテゴリを作る場合はフィルターも追加）。
3. 販売開始後、LINE Creators Marketで実際の販売URLを確認してから `.soon` を公式購入リンクに変更。
4. 専用ページ・トップページ両方でモバイルQAとリンク確認を実行。販売状況が未確認なら「申請準備中」や「企画中」のまま。
5. スタンプ画像を公開リポジトリへ投入する前には著作権と公開承認を確認。
